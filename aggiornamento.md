# Aggiornamento tema
## Main
1) Aggiornare ***horizon-from-shopify*** da https://github.com/BTWInformatica/horizon-from-shopify -> sync fork
2) GithHub Desktop -> ***horizon-from-shopify*** -> Current Branch -> ***Main*** -> Fetch origin
3) GithHub Desktop -> ***btw-horizon*** -> Current Branch -> ***Main*** -> Fetch origin
4) Repository -> Settings
5) Remote da https://github.com/BTWInformatica/btw-horizon.git a https://github.com/BTWInformatica/horizon-from-shopify.git
6) Branch ***main*** -> Fetch origin -> Push
7) GithHub Desktop -> Repository -> Settings
8) Remote da https://github.com/BTWInformatica/horizon-from-shopify.git a https://github.com/BTWInformatica/btw-horizon.git
9) Branch ***main*** -> Fetch origin -> Push

## BTW - Horizon
1) GithHub Desktop -> Current Branch -> ***BTW-Horizon***
2) Branch -> Merge into current branch (**main** -> ***Btw-Horizon***)-> Create a merge commit
3) Push

## Branch clienti
1) GithHub Desktop -> Current Branch -> ***Branch cliente***
2) Branch -> Merge into current branch (**Btw-Horizon** -> ***Branch cliente***)-> Create a merge commit
3) Push
